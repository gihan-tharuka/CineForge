### Decisions
- [decision] UI system: shadcn/ui on React 19 + Vite 6 + Tailwind CSS 4. Not explicitly named in architecture spine but is the de facto standard for React + Tailwind. [ASSUMPTION]
- [decision] Form factor: web dashboard (desktop-first, responsive) + backend-served interstitial (mobile-first). Dashboard for directors on laptops/desktops; interstitial for moviegoers on phones.
- [decision] Light mode default with dark mode toggle. Directors may work late; dark mode is a setting, not the default.
- [decision] Redirect interstitial is a separate surface from the SPA — served by .NET backend as a Razor view (AD-2). Minimal HTML/CSS, no framework, no bundle.
- [decision] Brand posture: professional, focused, cinematic-without-gimmick. No streaks, no badges, no celebratory animation. The tool gets out of the way.
- [decision] Color palette: deep slate primary (#0F172A, like a cinema screen), warm amber accent (#F59E0B, like projector light). Restrained — one accent, used sparingly.
- [decision] Typography: Inter for body/labels (clean, readable, professional). No display serif — clarity over decoration.
- [decision] Session: 24-hour expiry, 5 failed attempts → 15-minute lockout (FR-1, AD-6).
- [decision] No keyboard-first interaction model for v1 (unlike the Drift example). Directors use mouse/trackpad. Keep interaction surface simple.
- [decision] No streaks, badges, or achievement notifications. Counter-metrics SM-C1: do not optimize interstitial dwell time.

### Concern scan
- Accessibility: WCAG 2.1 AA (web dashboard). Interstitial must be readable at large text sizes.
- Platforms: web (dashboard, desktop-first), web (interstitial, mobile-first). No native app (out of scope).
- Brand: professional, cinematic, restrained. No movie-themed decoration.
- Regulated language: none (not healthcare/finance).
- Motion: minimal. No celebratory animations.
- i18n: English only for v1. [ASSUMPTION]
- Dark mode: supported, toggle in settings.
- Offline: not a concern for v1 (directors need connectivity for redirect changes).
- Content density: moderate. Dashboard shows scan counts and analytics at a glance.
- Input modalities: mouse/trackpad + touch (dashboard on tablets). Interstitial is touch-only.
- Notifications: email digest only (deferred from v1 per PRD). No push notifications.

### Journeys
- UJ-1: David (film director) launches a new campaign — surprise YouTube interview. Logs in, pastes URL, saves, sees confirmation.
- UJ-2: David checks campaign performance mid-week — views analytics, exports CSV.
- UJ-3: Amaya (moviegoer) scans QR code at Scope Cinema — interstitial loads, geolocation requested, redirect to YouTube.
